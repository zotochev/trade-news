# Задание: календарь вынужденных потоков, плечо в крипте, события РФ

Источник идеи — отчёт в соседнем проекте: `/opt/economy-model-lab/reports/Что двигает цену и вынужденные участники.md`
(разделы 3–5). Коротко: есть участники, которые **обязаны** купить или продать по правилу, марже, календарю или
мандату, а не потому что им нравится цена. Их потоки предсказуемы. trade-news собирает **датированные события** и
сырые данные, которые надо копить самим, и шлёт оповещения. Модели и учебный экран («слой 8») делает дашборд
`economy-model-lab`: он читает календарь отсюда через API.

Решения заказчика по умолчанию (можно поменять, спросите у него):
- дашборд читает календарь через API trade-news;
- оповещения: недельный дайджест в понедельник утром + напоминание накануне крупных событий;
- оповещение «риск каскада» в крипте **пока не делаем** — только копим данные;
- платные источники не подключаем.

Порядок: часть A сейчас, B и C — следующими, отдельными шагами. Каждая часть — законченный кусок: тесты, README/TODO,
коммит, перезапуск сервиса.

## Часть A. Календарь вынужденных потоков

### Что хранить
Отдельная сущность «запланированное событие» (не новость). Предлагаемые поля:

| Поле | Смысл |
|---|---|
| `date`, `time` (опц.), `tz` | когда; время — если известно (закрытие биржи, время аукциона) |
| `type` | код типа события, список ниже |
| `market` | `us_equity`, `us_rates`, `fx`, `crypto`, `ru` |
| `assets` | тикеры или активы, если событие про конкретные бумаги (`AAPL`, `BTC`, `USD/RUB`) |
| `title`, `details` | по-русски, коротко: кто вынужден и в какую сторону |
| `precision` | `exact` (дата известна) или `estimated` (оценка, например локап = IPO + 180 дней) |
| `size` (опц.) | оценка масштаба, если есть (доля предложения для разлока, объём аукциона) |
| `source`, `url` | откуда событие |

Дедупликация по (`type`, `date`, `assets`); пересчёт рассчитываемых дат — идемпотентный.

### Какие события

**Рассчитываемые** — без внешних источников, на год вперёд:

| `type` | Правило | Кто вынужден |
|---|---|---|
| `opex_monthly` | третья пятница месяца | маркетмейкеры снимают хеджи |
| `opex_quarterly` | третья пятница марта/июня/сентября/декабря («тройная ведьма») | то же, сильнее; плюс квартальная ребалансировка S&P в тот же день |
| `vix_expiry` | среда за 30 дней до третьей пятницы следующего месяца (проверить по календарю Cboe) | хеджи по VIX |
| `month_end`, `quarter_end` | последний рабочий день (по календарю NYSE) | ребалансировка пенсионных фондов, хедж валюты иностранцами, «причёсывание» портфелей |
| `russell_recon` | реконституция Russell — **расписание уточнить** на сайте FTSE Russell (было: последняя пятница июня; объявлялся переход на полугодовую) | индексные фонды малых компаний |
| `ru_minfin_announce` | 3-й рабочий день месяца (по календарю РФ) | Минфин объявляет покупки/продажи валюты по бюджетному правилу |
| `ru_tax_period` | ~28-е число (уточнить даты уплаты НДПИ, НДС, налога на прибыль) | экспортёры продают валюту → рубль крепнет |
| `btc_halving` | по текущей высоте блока (mempool.space API), оценка даты | майнеры |

**Из внешних источников:**

| `type` | Источник | Заметки |
|---|---|---|
| `earnings` → `buyback_blackout` | Finnhub earnings calendar (ключ уже есть) | тихий период ≈ за 2–4 недели до отчёта; хранить сам отчёт и выводить окно (precision `estimated`) |
| `ipo_lockup` | Finnhub IPO calendar | дата = IPO + 180 дней (иногда 90), `estimated`; если в 424B/S-1 есть точный срок — `exact` |
| `ust_auction` | TreasuryDirect API (`/TA_WS/securities/upcoming`) | объём, срок; крупные — refunding (февраль/май/август/ноябрь) |
| `token_unlock` | уже есть коллектор `token_unlocks` | просто отдавать его записи в общем календаре |
| `index_change` | пресс-релизы S&P DJI, MSCI (квартальные пересмотры: февраль/май/август/ноябрь), Nasdaq-100 (декабрь) | **хрупко**: если страницы не отдаются стабильно — ручной ввод в админке вместо парсинга |
| `cb_meeting` | уже есть (ff_calendar, RSS ЦБ) | отдавать в календаре |

### API для дашборда
`GET /calendar?from=YYYY-MM-DD&to=YYYY-MM-DD&types=...&markets=...` → список событий с полями выше, сортировка по
дате. Без авторизации, как остальной API (если у API есть авторизация — сказать заказчику, как дашборду её пройти).
Дашборд вызывает раз в час и кэширует; недоступность API у него обрабатывается.

### Доставка
- **Понедельник утром**: дайджест «вынужденные потоки на неделе» — сгруппировано по дням, для каждого события одна
  строка «кто вынужден и куда», крупные — выделены.
- **Накануне** крупных событий (квартальная экспирация, конец квартала, refunding, индексная ребалансировка, разлок
  > 5% предложения, анонс Минфина): короткое напоминание.
- Страница «Календарь» в админке: таблица на 4–8 недель с фильтрами по типу и рынку; ручное добавление и правка
  событий (для `index_change` и того, что не парсится).

### Готово, когда
- календарь на год вперёд заполняется; повторный запуск не плодит дубли;
- `/calendar` отдаёт события, тест на эндпоинт;
- дайджест и напоминания приходят (проверить на тестовом чате или dry-run);
- в README — список типов событий и источников; в TODO — что осталось хрупким.

## Часть B. Плечо в крипте (копим историю)

Бесплатные API бирж дают текущие значения, но не историю — её надо копить самим.

- **Что**: открытый интерес, ставка фандинга, соотношение лонгов и шортов, по возможности — ликвидации (через
  websocket-потоки ликвидаций Binance/Bybit/OKX), по BTC, ETH и топ-10 по открытому интересу.
- **Частота**: снимок каждые 5–15 минут; ликвидации — агрегировать по минутам.
- **Хранение**: отдельная таблица временных рядов; ретеншн — не меньше 2 лет (это и есть ценность).
- **API**: `GET /crypto/leverage?asset=BTC&from=&to=` для дашборда.
- **Оповещения пока не делаем.** Позже: «риск каскада» = рекордный открытый интерес + экстремальный фандинг.
- Ориентир важности: 10–11 октября 2025 года принудительно закрыто > $19 млрд позиций, ~70% за 40 минут.

## Часть C. Россия

- `ru_minfin_ops`: в день анонса Минфина (3-й рабочий день) — парсить сообщение на minfin.gov.ru: объём покупок/продаж
  валюты на месяц, ежедневный объём; плюс решение ЦБ о «зеркалировании» (cbr.ru). Событие + сразу уведомление.
- `ru_dividend_cutoff`: даты отсечек дивидендов по бумагам индекса Мосбиржи (ISS Мосбиржи, бесплатно).
- `ru_fx_rule`: изменения нормы обязательной продажи валютной выручки (новости ЦБ/правительства) — ручной ввод или
  фильтр новостей.
- Открытые позиции физлиц/юрлиц во фьючерсах Si и RTS (ISS Мосбиржи) — копить дневные значения, отдавать через API.
